# Exercises

Try each task before looking up a solution. Run scripts from the repository
root, for example:

```bash
python 07-exercises/loop.py
```

## Loop practice

`loop.py` prints the multiplication table for a number you enter. Try extending
it to ask for a table length or to print tables for several numbers.

## Collections practice

`sets-and-dictionaries.py` contains commented practice snippets. Uncomment one
small section at a time and predict the result before running it. Then try:

- Build a dictionary of words and their meanings, then look up a word.
- Read several numbers into a set and compare the results when inputs repeat.
- Compare values such as `20`, `20.0`, and `"20"` in a set.

Use the related examples in [`../03-collections/`](../03-collections/) when
you need a reference.
